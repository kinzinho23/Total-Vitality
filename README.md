<h1 align="center">💪 Total Vitality</h1>

<p align="center">
  <strong>Aplicação web para acompanhamento de saúde, alimentação, hidratação e exercícios.</strong>
</p>

<hr>

<h2>📖 Sobre o Projeto</h2>

<p>
  O <strong>Total Vitality</strong> é uma aplicação web voltada para
  <strong>saúde, bem-estar e acompanhamento físico</strong>.
  O sistema foi desenvolvido com o objetivo de permitir que o usuário
  acompanhe sua alimentação, consumo de água e rotina de exercícios
  em um único ambiente.
</p>

<h2>✨ Principais Funcionalidades</h2>

<ul>
  <li>👤 Sistema de cadastro e autenticação de usuários;</li>
  <li>🔥 Controle de calorias diárias;</li>
  <li>🥩 Acompanhamento de proteínas;</li>
  <li>🍚 Acompanhamento de carboidratos;</li>
  <li>🥑 Acompanhamento de gorduras;</li>
  <li>💧 Controle do consumo de água;</li>
  <li>🏋️ Gerenciamento de treinos e exercícios;</li>
  <li>📝 Criação de treinos personalizados;</li>
  <li>📊 Acompanhamento dos dados do usuário;</li>
  <li>💾 Armazenamento das informações em banco de dados.</li>
</ul>

<h2>🛠️ Tecnologias</h2>

<p>O projeto foi desenvolvido utilizando:</p>

<ul>
  <li><strong>PHP</strong></li>
  <li><strong>MySQL / MariaDB</strong></li>
  <li><strong>HTML5</strong></li>
  <li><strong>CSS3</strong></li>
  <li><strong>JavaScript</strong></li>
  <li><strong>Bootstrap</strong></li>
</ul>

<h2>🎯 Objetivo</h2>

<p>
  O <strong>Total Vitality</strong> busca oferecer uma maneira simples e
  organizada de acompanhar diferentes aspectos relacionados à
  <strong>alimentação, hidratação e exercícios físicos</strong>,
  permitindo que o usuário tenha maior controle sobre sua rotina
  e seus objetivos.
</p>
